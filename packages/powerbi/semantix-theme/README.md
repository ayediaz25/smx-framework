# SMX.Theme

Version: 1.0.0

Official Power BI Theme for the SMX Framework.

---

## Purpose

SMX.Theme provides a consistent visual identity for every dashboard built with the SMX Framework.

It standardizes colors, typography and chart palettes across executive, operational and analytical reports.

---

## Features

- Corporate color palette
- Power BI compatible
- Dark theme
- Consistent chart colors
- Typography standards

---

## Includes

- Theme JSON
- Color palette
- Typography guide
- Import instructions
- Dashboard recommendations

---

## Compatibility

Power BI Desktop

Power BI Service

SMX Framework
