# SMX.Badge

Version: 1.0.0

Enterprise Badge Component for the SMX Framework.

---

## Purpose

SMX.Badge is the standard component used to display statuses, categories and labels across dashboards.

It provides a consistent visual language for operational and executive interfaces.

---

## Features

- Status indicator
- Multiple variants
- Multiple sizes
- Power BI compatible
- HTML reference implementation
