# SMX.GraphCard

Version: 1.0.0

Enterprise Graph Container for the SMX Framework.

---

## Purpose

SMX.GraphCard is the standard container used to display charts and visual analytics.

It provides a consistent structure for every chart used across dashboards.

---

## Features

- Standard chart container
- Executive header
- Optional footer
- Multiple visual styles
- Responsive layout
- Power BI compatible
