# SMX.ExecutiveSummary

Version: 1.0.0

Enterprise Executive Summary Component for the SMX Framework.

---

## Purpose

SMX.ExecutiveSummary is the standard component for presenting business insights and narrative summaries in dashboards.

Instead of displaying raw numbers, it communicates the most relevant conclusions in a structured and executive-friendly format.

---

## Features

- Standard executive layout
- Business insight focused
- Power BI compatible
- HTML reference implementation
- Multiple visual styles
- Reusable design tokens
