# SMX.PageHeader

Version: 1.0.0

Enterprise Page Header Component for the SMX Framework.

---

## Purpose

SMX.PageHeader standardizes the header section of dashboards and applications.

It provides a consistent place for titles, subtitles, actions and filters.

---

## Features

- Dashboard title
- Subtitle
- Optional icon
- Action area
- Filter area
- Responsive

---

## Recommended Use

✔ Dashboard pages

✔ Reports

✔ CRM modules

✔ Internal portals
