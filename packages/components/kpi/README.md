# SMX.KPI

Version: 1.0.0

Enterprise KPI Component for SMX Framework.

---

## Purpose

SMX.KPI is the standard component for displaying business metrics in dashboards built with the SMX Framework.

It provides a consistent visual language across executive, operational and analytical dashboards.

---

## Features

- Responsive layout
- Enterprise visual style
- Multiple visual variants
- Compatible with Power BI
- HTML reference implementation
- Reusable design tokens

---

## Anatomy

A KPI consists of:

- Icon
- Title
- Main Value
- Subtitle
- Trend
- Status
- Badge
- Last Update

---

## Recommended Use

✔ Executive dashboards

✔ Operational dashboards

✔ Financial dashboards

✔ Commercial dashboards

✔ Support dashboards
