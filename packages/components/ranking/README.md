# SMX.Ranking

Version: 1.0.0

Enterprise ranking component for the SMX Framework.

---

## Purpose

Displays Top N records such as products, customers, vendors or regions.

---

## Features

- Top 5
- Top 10
- Ranking bars
- Percentage support
- Responsive

---

## Variants

Light

Dark

Glass

---

## Recommended Usage

- Sales Ranking

- Product Ranking

- Customer Ranking

- Regional Ranking

- Executive Dashboards
