# SMX.Table

Version: 1.0.0

Enterprise data table component for the SMX Framework.

---

## Purpose

SMX.Table standardizes tabular data presentation across dashboards.

Designed for operational, executive and analytical reports.

---

## Features

- Responsive
- Sortable
- Zebra rows
- Hover states
- Theme support
- Power BI compatible

---

## Variants

Light

Dark

Glass

---

## Recommended Usage

- Operational Reports
- Executive Reports
- Support Dashboards
- Commercial Dashboards
