# SMX.Table

Version: 1.0.0

Enterprise data table component for the SMX Framework.

---

## Purpose

SMX.Table standardizes tabular data presentation across dashboards.

Designed for operational, executive and analytical reports.

---

## Features

- Responsive
- Sortable
- Zebra rows
- Hover states
- Theme support
- Power BI compatible

---

## Variants

Light

Dark

Glass

---

## Recommended Usage

- Operational Reports
- Executive Reports
- Support Dashboards
- Commercial Dashboards

## Component Properties

| Property | Type | Default | Description |
|-----------|------|---------|-------------|
| striped | boolean | true | Alternate row colors |
| hover | boolean | true | Row highlight |
| sortable | boolean | true | Sort columns |
| stickyHeader | boolean | true | Fixed header |
| responsive | boolean | true | Responsive layout |
| pagination | boolean | false | Enable pagination |
| search | boolean | false | Search bar |
