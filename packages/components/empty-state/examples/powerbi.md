# Power BI Guidelines

Recommended Width

500–700 px

---

Recommended Height

250–350 px

---

Recommended Usage

- Empty tables

- Empty charts

- No search results

- Access denied

- Data loading

---

Best Practices

✔ Explain why data is unavailable.

✔ Suggest the next action.

✔ Use a friendly icon.

✔ Keep the message short.
