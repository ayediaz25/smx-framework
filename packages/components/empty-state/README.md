# SMX.EmptyState

Version: 1.0.0

Enterprise empty state component for the SMX Framework.

---

## Purpose

SMX.EmptyState provides a consistent experience when no data is available.

---

## Features

- Empty datasets
- Search without results
- Missing permissions
- Error state
- Loading placeholder support

---

## Variants

Default

Search

Error

No Permissions

Loading

---

## Recommended Usage

- Dashboards
- Reports
- Tables
- Graphs
- Filter Results
