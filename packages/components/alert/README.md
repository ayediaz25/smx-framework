# SMX.Alert

Version: 1.0.0

Enterprise Alert Component for the SMX Framework.

---

## Purpose

SMX.Alert is the standard component used to communicate important information, warnings, errors and success messages across dashboards.

---

## Features

- Four alert types
- Responsive layout
- Optional icon
- Optional badge
- Power BI compatible
- HTML reference implementation

---

## Recommended Use

✔ Notifications

✔ Validation

✔ Warning messages

✔ Success confirmations

✔ Information panels

---

## Avoid Using For

✘ Navigation

✘ KPI

✘ Long reports
