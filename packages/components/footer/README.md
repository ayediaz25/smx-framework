# SMX.Footer

Version: 1.0.0

Enterprise Footer Component for the SMX Framework.

---

## Purpose

SMX.Footer standardizes the footer section of dashboards and applications.

It provides a consistent area for metadata, source information, refresh timestamps and branding.

---

## Features

- Source information
- Last refresh
- Dashboard version
- Corporate branding
- Responsive layout

---
