# Accessibility

## Overview

The Commercial Dashboard follows SMX Framework accessibility guidelines.

---

## Keyboard Navigation

- Full keyboard support
- Logical tab order
- Visible focus indicators
- Skip navigation support

---

## Contrast

Minimum contrast ratio:

- Text: 4.5:1
- Large text: 3:1

---

## Screen Readers

Supports:

- aria-label
- aria-labelledby
- aria-describedby

---

## Icons

Every icon should include an accessible label.

---

## Tables

Ranking and sales tables include:

- Table headers
- Row headers
- Keyboard navigation
- Responsive scrolling

---

## Charts

Every chart must include:

- Alternative description
- Data summary
- Tooltip support

---

## Responsive

Supported resolutions

- Desktop
- Laptop
- Tablet
