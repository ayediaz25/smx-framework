# Commercial Dashboard Layout

## Structure

```
Page Header
────────────────────────────────────

Sidebar | KPI Cards

Sidebar | Sales Trend | Sales Channel

Sidebar | Product Ranking | Province Map

Sidebar | Filters | Table
```

## Layout Sections

### Header

Contains:

- Global Search
- Notifications
- User Profile
- Date Selector

---

### Sidebar

Navigation between:

- Dashboard
- Sales
- Customers
- Products
- Channels
- Reports
- Settings

### Main Content

Includes:

- KPI Summary
- Sales Trend
- Sales Channel Distribution
- Product Ranking
- Province Analysis
- Customer Analytics

Optional.

- Version
- Last Refresh
