# SMX.Layout.TwoColumns

Version: 1.0.0

Two-column responsive layout for enterprise dashboards.

---

## Purpose

Provides a reusable two-column structure for arranging dashboard content.

---

## Features

- Responsive Grid
- Equal Columns
- Configurable Gap
- Theme Compatible

---

## Typical Usage

- KPI + Ranking

- Graph + Table

- Timeline + Alerts

- Executive Summary + Graph
