# SMX.Layout.DashboardGrid

Version: 1.0.0

Standard dashboard layout used by all SMX dashboard templates.

---

## Purpose

DashboardGrid defines the base structure for enterprise dashboards.

It provides a consistent arrangement of headers, content areas and footers while remaining independent from the visual components.
