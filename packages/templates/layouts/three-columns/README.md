# SMX.Layout.ThreeColumns

Version: 1.0.0

Three-column responsive layout for enterprise dashboards.

---

## Purpose

Provides a reusable three-column structure for arranging dashboard components.

---

## Features

- Responsive Grid
- Equal Columns
- Adjustable Gap
- Theme Compatible

---

## Typical Usage

- Three KPI Groups

- Three Graph Cards

- Three Tables

- KPI + Graph + Ranking
