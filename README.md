## 📌 Overview

SMX Framework is an enterprise UI framework designed to standardize Power BI dashboards.

The framework provides reusable assets, themes, HTML components, DAX libraries, templates and documentation to accelerate dashboard development while maintaining a consistent visual identity.

---

## ✨ Features

- 🎨 Enterprise Design System
- 📊 Power BI Themes
- 🧩 HTML Components
- 📈 Reusable DAX Library
- 📐 Layout Templates
- 📚 Documentation
- 🖼 Asset Library
